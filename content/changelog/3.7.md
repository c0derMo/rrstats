### Revamped leaderboards

The leaderboards got a visual update, with a lot of leaderboards getting new columns, added color, and more detailed information!
A lot of the columns are also custom sortable as well, so you can gather many more stats from the page now.
The names of leaderboards were also adjusted, to streamline them a bit more.
A couple new leaderboards were also added, namely:

- Roulette Rankings
- Best RR Placement
- Most medals won
- Most maps won (specific map)
- Most matches swept (8+ points)
- Highest map winrate (random maps)

### Minor improvements

- Berlin spins are now filtered independently of the target number. If you filter for "Falling Object" / "Dealer" on the spins page for berlin, it will show all spins where "Falling Object" / "Dealer" was a condition for _any_ target, not just the target where you entered it.
- RRs played is now computed properly on the compare page and API used by hitmaps, previously multiple bracket finishes were counted as seperate tournaments.
